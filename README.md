# 📰 News App

A modern and clean **Flutter News Application** that allows users to browse and read the latest news articles from different categories with a smooth and responsive user experience.

---

## 📱 Features

- 📰 Browse latest news articles  
- 📂 Multiple news categories  
- ⚡ Smooth and responsive UI  
- 🌍 Multi-language support
- 🌐 Real-time news using REST APIs  

---

## 🛠️ Tech Stack

- 💙 Flutter  
- 🎯 Dart  
- 🧠 Bloc / Cubit (State Management)  
- 🌐 REST APIs  
- 📦 Dio (HTTP Client)  

---


## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohamed-ahmed-coding/News_App.git
```

### 2. Navigate to project folder

```bash
cd News_App
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
